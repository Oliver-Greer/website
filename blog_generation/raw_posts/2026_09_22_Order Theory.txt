Notes on "Introduction to Lattices and Order" by B.A. Davey and H.A. Priestley.

<b>Definitions:</b>
<ul>
    <li>
        <b>Partial Order:</b> Let P be a set. A partial order on P is a binary relation <= such that for all x,y,z in P:
        <ul>
            <li>x &lt;= x (reflexivity)</li>
            <li>x &lt;= y and y &lt;= x => x = y (antisymmetry)</li>
            <li>x &lt;= y and y &lt;= z => x &lt;= z (transitivity)</li>
        </ul>
        If the above conditions are met, then P is an ordered set or poset. 
        Notation varies but typically P is shown as &lt;P;\&lt;=>. 
        Any any set an order = is called the discrete order.

        If condition 2 on any set Q is not met, but condition 1 and 3 
        are (&lt;= is not antisymmetric) then &lt;= is called a quasi-order or pre-order.
    </li>
    <li>
        <b>Comparability:</b> If x !&lt;= y and y !&lt;= x, then x and y are not comparable.
        Comparability is denoted by ||.
    </li>
    <li>
        <b>Forming New Ordered Sets From Existing Ones:</b> Any subset Q of a poset P gets its ordering from P. 
        This is called an induced order.
    </li>
</ul>
